JavaScript 进阶：原型链、继承与 class

发表于2026-09-24|更新于2026-09-24|JavaScript进阶
|字数总计:598|阅读时长:2分钟|阅读量:

对象属性从哪里来

读取对象属性时，引擎先检查对象自身；如果没有，就沿着它的内部原型继续查找，直到找到属性或到达 null。这条查找路径叫原型链。

Object.create(animal) 创建一个以 animal 为原型的新对象。方法中的 this 仍由调用方式决定，所以 dog.speak() 中它指向 dog。

原型链和 constructor

普通函数有一个 prototype 属性，使用 new Fn() 创建的对象会把该函数的 prototype 设为自己的原型。通过 Object.getPrototypeOf(obj) 读取实例原型。

不要通过 user.proto 编写通用库逻辑；优先使用标准 API Object.getPrototypeOf 和 Object.setPrototypeOf。频繁修改已有对象的原型也可能影响引擎优化。

class 是原型机制的语法

extends 建立实例方法和静态成员所需的原型关系。子类构造函数中，必须先调用 super(...) 才能使用 this。方法定义在类的原型上，不会为每个实例重复创建一份。

属性覆盖与危险键

给对象赋值时，如果原型上有同名属性，通常会在对象自身创建一个属性来遮蔽它，不会改写原型。判断自有属性用 Object.hasOwn(obj, key)；key in obj 会连原型属性一起检查。
