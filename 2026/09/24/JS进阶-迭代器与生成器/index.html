JavaScript 进阶：迭代器、可迭代对象与生成器

发表于2026-09-24|更新于2026-09-24|JavaScript进阶
|字数总计:553|阅读时长:2分钟|阅读量:

for…of 使用迭代协议

可迭代对象实现 Symbol.iterator 方法。调用它应返回一个迭代器；迭代器有 next() 方法，每次返回 { value, done }。

数组、字符串、Map、Set 等都可迭代，因此可以用于 for...of、展开语法和 Array.from。普通对象默认不可迭代，所以直接对普通对象使用 for...of 会报错。

生成器帮你创建迭代器

生成器函数用 function* 声明，执行时返回迭代器；执行到 yield 会暂停并产出一个值，下次调用 next() 再从暂停处继续。

无限生成器只有在按需读取时才不会一次性创建全部数据。若直接对它展开成数组，会一直运行并耗尽内存。惰性序列适合分页、数据流和大型组合计算。

生成器也能接收值

对生成器迭代器调用 next(value)，这个值会成为上一个 yield 表达式的结果：

第一次 next(value) 传入的参数会被忽略，因为还没有暂停的 yield 等待它。

迭代结束与资源清理

消费方提前退出 for...of 时，迭代器如果提供 return()，运行时会调用它。这可用于关闭文件、游标等资源；生成器中的 finally 可执行清理逻辑。

异步数据流使用 Symbol.asyncIterator 和 for await...of。它们适合逐步等待网络流或异步分页结果，但要确认运行时支持。
